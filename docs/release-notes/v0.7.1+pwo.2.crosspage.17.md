# BabelDOC 0.7.1+pwo.2.crosspage.17

## Changes

- Ordinary document translation completes before the optional cross-page and cross-column enhancement. Failed or rejected enhancement groups retain the translated baseline; ordinary translation and actual output errors still fail.
- Continuations are translated as complete sentences, matched by explicit response IDs and written into isolated candidates. Shared paragraphs, cancellation, multi-output publication and rollback receive consistency checks.
- Numeric expressions, formula and style ownership, output bounds and source identity remain guarded. Rotated text and verified source spacing are preserved. Automatic glossary suggestions remain scoped to their source context.
- TOC output I/O failures propagate. If the filesystem also refuses publication rollback, the task fails with the original error, restoration failures and recovery backup paths; its report identifies the uncertain output state.
- Candidate eligibility rejects independent numbered paragraphs, explicit non-body objects, small-font paragraphs and adjacent caption fragments before model selection. These cases retain ordinary translation.

## Acceptance and accepted limitations

On 2026-11-13, nine real two-page papers were translated through the installed Windows backend using the locally configured DeepSeek model alias `deepseek-flash`. All nine produced monolingual and bilingual PDFs. Three of eleven designated continuation targets were translated together and applied, while eight retained ordinary translation.

The user accepted the current version for merge with the following limitations:

- General translation semantics and terminology, version strings and URLs, bibliography layout, labels, footers and preservation of existing PDF link annotations require further work in a later version.
- Chinese words may split across a page or column boundary. Complete-sentence translation does not guarantee natural placement of every translated phrase on its original page.
- Strict number, formula and layout checks intentionally remain conservative. They may reject acceptable formatting changes and leave a continuation in the ordinary translation.
- Acceptance used the installed desktop backend and a limited UI startup check. It was not nine complete mouse-driven desktop tasks. Interrupted subagent reviews were reported separately from completed independent reviews.

The feature remains optional and disabled by default. This version does not guarantee every boundary is identified, every translation is correct, or all PDF layout and interaction features are preserved. No source papers, translated PDFs, credentials or private model transcripts are included in the repository.
